
# 🧮 Calculator

A modern and responsive calculator built with **HTML, CSS, and JavaScript**.
It features a clean interface, simple controls, and a smooth user experience.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal numbers
* 🧹 Clear button
* 📱 Responsive design
* 🎨 Clean and modern interface

## 🛠️ Technologies

* **HTML5** — Structure
* **CSS3** — Design & Responsive Layout
* **JavaScript** — Calculator functionality

## 🚀 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/soulaf-ouachekradi-ai/calculator.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
